# 应用更新

打开青学首页 → 关于与帮助 → 检查更新。

- 默认只在你点击时检查。打开“自动检查更新”后，访问首页时最多每天检查一次，不自动下载或安装。
- 默认只在免费 Wi-Fi 下下载。其他网络会询问是否只对本次使用流量，取消不会改动当前版本。下载可取消，失败后可重新下载。
- 稳定版渠道仅接收稳定版；测试版渠道也能接收稳定版。只提供适合手机架构和 Android 版本的更新。
- 下载完成后核对文件、应用名称标识、版本和证书。通过后点“前往安装”，由系统确认；可能需先允许青学安装应用更新。
- 取消安装保留现有版本。应用更新不主动删除模型、词库、设置或学习记录。模型仍在各自管理页面按需下载。

如果提示安装证书不一致，请等待版本迁移说明，**不要通过卸载清空数据尝试解决**。现有手机测试版使用开发证书，正式发行证书的迁移尚需单独处理。

开源仓库：[qingxue-inputmethod-android](https://github.com/fwfeded/qingxue-inputmethod-android)。当前已公开源码和签名版本清单，尚未公开正式签名 APK；首次检查显示尚无正式版本属于正常状态。
