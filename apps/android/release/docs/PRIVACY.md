# 青学 Android 隐私说明

普通拼音候选、英文词语释义与本地学习由手机上的引擎处理。学习数据保存在应用私有目录，可在设置中开关、管理、导出或清除。导出文件包含用户自己的词汇和习惯，请自行选择存放位置。卸载应用可能删除这些数据与下载模型。

语音来源由用户选择。离线模型下载完成后可在断网环境识别；选择手机语音服务时，其提供者可能联网；选择自行配置的在线语音时，音频与识别请求发送到设置中的服务器。局域网 ws 连接未加密，适用于可信局域网测试；跨公网应配置 wss。连接密钥仅用于该服务器认证，不在公共源码、日志或发行包中预设。

下载语音/文字模型会连接模型来源站点，产生网络请求与下载流量；站点可能获知网络地址。模型在应用私有空间保存，可单独删除。离线文字整理结果先与原文核对，由用户采用，可撤回；整理并不保证文字含义完全正确。

录音权限仅供语音输入使用；蓝牙、振动与音效相关权限用于选定的输入体验。项目没有把普通按键、候选文本或学习词频作为更新请求上传的设计。

本版尚未启用应用更新检查。拟议更新会仅获取版本与安装包信息，自动检查可关闭，安装由系统确认；接入后应同步本说明。此文件不替代用户选用的系统或自建服务的隐私约定。
