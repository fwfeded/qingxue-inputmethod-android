# 青学输入法 · Android 测试版

打中文，也认识一个英文词。青学是基于 [青简](https://github.com/qingjian-team/qingjian) Rust 引擎的独立 Android 输入法，保留候选英文释义、本地学习与词库管理。

当前源码基于 Android 0.24.1-maintenance（versionCode 35）。这是待审阅的开源准备快照，尚无正式 GitHub 下载渠道；不要把未签名构建产物当作可安装正式版。

支持拼音与候选、符号表情、主题和按键反馈、个人学习、语音输入、文字整理核对/采用/撤回。语音与文字模型按需下载，不预装在 APK 内。系统语音服务可用性随手机而异；自行配置的电脑语音服务依赖电脑在线。

目前不应宣称功能全部等同于任何商业输入法。长段落文字整理可能误改，必须核对原文；手机震感、耗电、厂商底部适配仍需真实设备反馈。当前 APK 尚无应用内自动更新；更新入口仍在预览讨论阶段。
